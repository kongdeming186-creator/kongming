# 城运街道综合管理平台

## 🚀 快速开始

### 方式一：一键启动（推荐）

双击 `启动.bat` 文件即可自动启动项目。

> 首次运行会自动安装依赖，需要几分钟时间，请耐心等待。

### 方式二：命令行启动

```bash
# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

启动成功后，在浏览器中访问：**http://localhost:5173/**

---

## 📦 打包部署

双击 `打包.bat` 文件，或运行：

```bash
npm run build
```

打包完成后，将 `dist` 目录部署到服务器即可。

## 🎯 功能模块

### 后台管理端
- **首页仪表盘**：数据概览、预警趋势、标签分布
- **居民信息管理**：居民列表、居民详情、标签管理
  - AI智能推荐：根据居民信息推荐可享受的政策
- **数据导入**：Excel批量导入居民数据
- **预警管理**：预警列表、预警规则配置
- **任务管理**：任务列表、任务详情
- **统计报表**：多维度数据统计分析

### AI功能
- **AI智能助手**（右下角悬浮按钮）
  - 政策问答：询问各类政策条件、申请流程、所需材料
  - 数据查询：快速获取系统统计数据
  - 智能搜索：自然语言搜索居民信息
  - 操作指引：系统功能使用帮助

- **智能标签推荐**（居民详情页）
  - 基于居民年龄、性别、健康状况等智能分析
  - 推荐可享受的政策，显示匹配度
  - 一键快速添加标签

## ❓ 常见问题

### Q1: 双击启动.bat没反应？
A: 请确保已安装 Node.js。下载地址：https://nodejs.org/  
安装时请勾选 "Add to PATH" 选项。

### Q2: 启动失败，提示端口被占用？
A: 关闭其他占用 5173 端口的程序，或修改 `vite.config.js` 中的端口配置。

### Q3: 页面空白？
A: 按 F12 打开开发者工具，查看控制台是否有报错信息。

### Q4: 如何停止服务器？
A: 在运行 `启动.bat` 的命令行窗口中按 `Ctrl + C`。
