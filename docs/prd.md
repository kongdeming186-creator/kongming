# 需求文档

## 1. 应用概述

### 1.1 应用名称
长丰街道基层治理市民热线诉求可视化大屏

### 1.2 应用描述
面向武汉市硚口区长丰街道办事处的Web可视化大屏应用，用于展示和分析市民热线诉求数据，支持高频问题溯源、新事件处置参考、趋势预测预警等功能。应用采用深色科技风格（深蓝/藏青为主色调，红色点缀预警信息），标准分辨率为1920x1080，适配大屏电视展示。

## 2. 用户与使用场景

### 2.1 目标用户
- 长丰街道办事处管理人员
- 各科室负责人（执法中队、公共服务办、公共管理办、城改办等）
- 决策层领导

### 2.2 核心使用场景
- 实时监控市民热线诉求整体态势
- 分析高频问题分布和区域特征
- 查询历史相似案例辅助新事件处置
- 识别高风险区域和趋势预警
- 数据汇报和决策支持

#### 3.3.3 事件点位标注（298个点位按社区归集分布）

**点位总数与分布规则**
- 地图上共298个事件点位
- 按20个社区区域精确归集分布
- 每个社区的事件点位必须集中在该社区地理范围内：以社区坐标为中心，偏移不超过0.003度（约300米）
- 同一社区内的事件点位围绕社区中心按向日葵螺旋状均匀散开分布，避免全部重叠

**社区点位数量分配规则**
- 每个社区的事件数量与其工单量成正比
- 天顺园北社区（1025件工单，最多）：点位约25个
- 正康社区（290件工单,最少）：点位约8个
- 其余社区按工单量比例分配点位数量，介于8-25个之间
- 总计298个点位

**高风险社区点位分布特征**
- 高风险社区（东风、天顺园北、天顺园南、长丰、园博北）的事件点位密度更高、分布更集中
- 高风险社区的偏移半径更小，点位更紧密

**点位颜色与类型**
- 使用不同颜色图标区分事件类型大类，共10类：
  - 城管类
  - 物业类
  - 安全类
  - 环保类
  - 民生类
  - 交通类
  - 市政类
  - 规划类
  - 违建类
  - 水务类

**点位数据生成规则**

- 覆盖全部20个社区

## 4. 业务规则与逻辑

### 4.1 风险评分规则
- 根据区域工单量、问题类型、办理时长等因素计算风险评分
- 评分范围0-100分，分数越高风险越大

### 4.2 风险分级规则
- 高风险：评分≥70分，地图标注红色
- 中风险：评分50-69分，地图标注橙色
- 低风险：评分<50分，地图标注绿色

### 4.3 社区热力色着色规则
- 根据社区诉求量计算热力色
- 高诉求量社区显示红色
- 中诉求量社区显示橙色
- 低诉求量社区显示绿色

### 4.4 高危区域热力图层计算规则
- 按工单密度和办结率综合计算危险指数
- 红色区域为高风险
- 橙色区域为中风险
- 绿色区域为低风险

### 4.5 事件点位分布规则
- 298个事件点位按20个社区区域精确归集
- 每个社区的事件点位以社区坐标为中心，偏移不超过0.003度（约300米）
- 同一社区内的事件点位围绕社区中心按向日葵螺旋状均匀散开分布
- 高风险社区（东风、天顺园北、天顺园南、长丰、园博北）的偏移半径更小，点位分布更集中
- 每个社区的事件数量与其工单量成正比：天顺园北约25个点位，正康约8个点位，其余社区介于两者之间

### 4.6 社区标签避让规则
- 社区名称文字标注与事件点位自动避让
- 有事件点的地方，社区标签自动上移

### 4.7 图层切换规则
- 点击「全部事件」按钮，显示所有298个事件点位
- 点击「仅高危事件」按钮，仅显示高风险等级的事件点位
- 点击「热力图层」按钮，显示高危区域热力图层

### 4.8 相似案例匹配规则
- 根据输入的新事件描述，匹配历史案例库
- 返回相似度最高的TOP5案例
- 匹配维度包括问题类型、关键词、区域等

### 4.9 季节预警规则
- 根据当前月份判断所属季节
- 基于历史数据预测当前季节的工单量和高频问题类型

### 4.10 数据刷新规则
- 接收到新工单时，自动更新相关数据面板
- 地图热力色叠加层实时刷新
- 高频问题排行实时更新
- 高危事件列表面板实时更新
- 事件点位标注实时更新

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 无历史数据 | 显示「暂无数据」提示 |
| 相似案例匹配无结果 | 显示「未找到相似案例」提示 |
| 地图区域点击无数据 | 显示「该区域暂无数据」提示 |
| 数据导出失败 | 显示「导出失败，请重试」提示 |
| 实时数据接口异常 | 显示「数据更新异常」提示，保留上一次数据 |
| 地图API加载失败 | 显示「地图加载失败」提示 |
| 事件点位无数据 | 不显示点位标注 |
| 高危事件列表为空 | 显示「当日暂无高危事件」提示 |
